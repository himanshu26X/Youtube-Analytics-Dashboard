**# 📊 YouTube Analytics Dashboard

An interactive, end-to-end data analytics dashboard built in **Tableau Public** to analyze creator metrics, audience growth trends, and viewer engagement patterns.

---

## 🚀 Dashboard Preview
https://github.com/himanshu26X/Youtube-Analytics-Dashboard/blob/3e8838b561898fee3d1b5ed8becb2d1aeeb4ce18/dashboard_preview.png

---

## 🛠️ Tech Stack & Tools
* **Visualization:** Tableau Public
* **Data Prep:** Excel / CSV Processing

---

## 📈 Key Metrics & Features
* **Core KPI Summary:** Instant visibility into total views, total likes, and subscriber acquisition.
* **Content Categorization:** Evaluates view distribution and engagement rates across video categories.
* **Top Content Ranking:** Highlights top-performing channels and videos to identify high-engagement patterns.
